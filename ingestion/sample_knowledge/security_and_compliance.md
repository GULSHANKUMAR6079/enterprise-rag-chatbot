# Security & Compliance Standards

## Compliance Certifications
Incerro maintains industry-leading compliance:
- **SOC2 Type II**: Audited annually by independent CPA firms covering Security, Availability, and Confidentiality trust principles.
- **ISO/IEC 27001:2022**: Certified Information Security Management System (ISMS).
- **GDPR & CCPA**: Full compliance with European and Californian data protection regulations, supporting right-to-erasure and data minimization.
- **HIPAA**: Available on dedicated Enterprise deployments with signed BAAs.

## Data Encryption & Zero-Trust
- All data in transit is encrypted using TLS 1.3 with forward secrecy.
- All data at rest is encrypted using AES-256 with customer-managed encryption keys (CMEK) option.
- Model inputs and outputs are never used to train foundation models without explicit contractual consent.
