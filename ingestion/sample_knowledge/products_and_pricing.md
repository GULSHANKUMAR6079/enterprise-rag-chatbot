# Products & Pricing: Incerro Platform

## Product Suite
Incerro provides three core software products:
1. **Incerro AI Gateway**: Centralized reverse proxy for LLM orchestration, intelligent retries, circuit breaking, model fallback hierarchies, and token budgeting.
2. **Incerro Guardrails Suite**: Ultra-fast deterministic inspection pipeline that intercepts prompt injections, role-play jailbreaks, financial PII, and API secret leakage.
3. **Incerro Knowledge Engine**: Enterprise RAG combining pgvector dense embeddings with Okapi BM25 sparse keyword indexing, reciprocal rank fusion, and indirect prompt injection defense.

## Pricing Tiers

- **Starter Tier ($49 / month)**:

  - Basic input normalization and secret scanning
  - Standard email support (48-hour response SLA)
- **Pro Tier ($199 / month)**:
  - Up to 1,000,000 monthly chat requests
  - Complete multi-stage guardrails (indirect injection defense, jailbreak protection)

- **Enterprise Tier (Custom Pricing)**:

  - 24/7 dedicated support with 15-minute emergency SLA
  - Custom Business Associate Agreement (BAA) and SOC2 reports
